## About
**Free Anime APIs** is a curated list of **free and paid Anime APIs** for developers.  
Whether you’re building a website, streaming platform, bot, mobile app, or dashboard — this repo has you covered:

✔ Anime Data  
✔ Streaming & Episodes  
✔ Manga APIs  
✔ Anime Quotes  
✔ Waifu & Character Images  
✔ Reverse Image Search  
✔ NSFW toggle APIs  
✔ Scraping-based sources  

This repo is updated regularly for developers, otakus, and weeb coders

## General Anime Data
API Source | Description | Auth | HTTPS | Type | Resources/Packages |
|---|---|---|---|---|---|
| [Jikan API](https://docs.api.jikan.moe/) | Unofficial MyAnimeList API with anime, manga, characters, schedules, rankings | No | Yes | Free | [github](https://github.com/jikan-me/jikan) |
| [AniList API](https://anilist.gitbook.io/anilist-apiv2-docs/) | Modern GraphQL API for anime/manga metadata | No | Yes | Free | - |
| [Kitsu API](https://kitsu.docs.apiary.io/) | Anime + manga metadata, trending lists, libraries | No | Yes | Free | - |
| [AniAPI](https://aniapi.com/docs) | Anime info, seasonal lists, filters, NSFW toggle | Yes | Yes | Free | - |
| [Nekosia API](https://nekosia.cat/documentation) | Random catgirl images with metadata, dominant colors, compressed versions, duplicate prevention, and its own booru | No | Yes | Free | - |
